# Video to Text Python

Convert video files (mp4, mkv, webm, avi, mov) to text transcripts using speech recognition. Supported languages: Russian (ru), Ukrainian (uk), and English (en).

## Requirements

- Python 3.8 or higher
- ffmpeg installed and available in PATH
- Python packages listed in `requirements.txt`

## Installation

Clone the repository and install dependencies:

```bash
git clone https://github.com/DontforgetAntaiku/video_to_text_python.git
cd video_to_text_python
pip install -r requirements.txt
```
## Usage

Run the main script:

```python
python main.py
```
